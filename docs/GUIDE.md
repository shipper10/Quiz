# دليل الاستخدام

كل شيء يتم من صفحة **المحرر** في الموقع (من القائمة الجانبية). التعديلات تُحفظ أولاً كـ«مسودة» في متصفحك ولا يراها الطلاب حتى تنشرها.

## 1) إضافة سنة / فصل / مادة

1. افتح **المحرر**.
2. **إضافة سنة** ← اكتب الاسم (مثلاً «السنة الثانية»).
3. داخل السنة اضغط **إضافة فصل**.
4. داخل الفصل اضغط **مادة جديدة** ← اكتب الاسم. ستفتح صفحة المادة.
5. في صفحة المادة: اضبط اللون، **اتجاه النص** (عربي = من اليمين لليسار)، وأضف **المصادر** (مثلاً «كتاب الدكتور فلان»، «محاضرات 2025»)، ثم **إضافة درس**.

> يمكن ربط نفس المادة بأكثر من فصل بزر **ربط مادة موجودة**.

## 2) إضافة الأسئلة

### الطريقة أ — من النموذج
داخل الدرس اضغط **سؤال جديد** ← اختر النوع ← املأ الحقول ← **حفظ** (أو «حفظ + سؤال جديد» لإدخال عدّة أسئلة بسرعة).
- زر **جرّبه كما يراه الطالب** يعرض السؤال كما سيظهر.
- قسم «ملاحظات على السؤال» يخبرك فوراً إن كان ينقصه شيء (مثل خيار فارغ أو إجابة غير محددة).
- لتعديل سؤال موجود: افتحه من قائمة الدرس، أو من **تصفّح الأسئلة ← تعديل السؤال**.
- النسخ والترتيب: أزرار **تكرار** والأسهم بجانب كل سؤال.

### الطريقة ب — بمساعدة الذكاء الاصطناعي (الأسرع)
1. داخل الدرس اضغط **استيراد JSON**.
2. اضغط **نسخ — AI format guide**: ينسخ شرح الصيغة المطلوبة.
3. الصقه في ChatGPT/Claude مع نص الأسئلة (أو صورة/PDF) واطلب: «حوّلها إلى هذه الصيغة».
4. الصق النتيجة في مربع الاستيراد ← **تحقّق وأضف**.
   الأسئلة السليمة تُضاف، وغير السليمة (أو المكرّرة) تُتجاهل مع إخبارك بعددها.

### كتابة الصيغ الكيميائية والرياضية
داخل أي نص: `$H_2O$` ← H₂O ، `$Ca^{2+}$` ← Ca²⁺ ، `$alpha$` ← α ، و`**كلمة**` ← **غامق**. والسطر الجديد يُحفظ كما هو.

## 3) الصور (أسهل طريقة)

داخل نموذج السؤال في خانة **صورة**:
- **اختر صورة** من الجوال أو الحاسوب، أو
- **التقط صورة** بالكاميرا مباشرة، أو
- **الصق** الصورة (Ctrl+V، أو اضغط مطولاً ثم «لصق») أو **اسحبها** إلى المربع.

تُصغَّر الصورة تلقائياً (حتى 1400 بكسل) وتُحفظ كملف عادي داخل `images/` (بدون Base64 داخل الأسئلة)، فلا يتضخم الملف. يمكنك كتابة «وصف الصورة» لقارئات الشاشة.
في أسئلة التوصيل ضع الصورة التي تحمل الخيارات (A–E) ثم اجعل الخيارات `A` `B` `C`…

## 4) النشر (ليراه الطلاب)

التعديلات تظهر لك أنت فقط حتى تنشرها. من **المحرر** ← **التعديلات غير المنشورة** عندك خياران:

**أ) نشر مباشر إلى GitHub (موصى به)** — مرة واحدة تجهّز مفتاح وصول:
1. GitHub ← صورتك ← **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access:** Only select repositories ← اختر مستودع الموقع.
3. **Permissions → Repository permissions → Contents: Read and write**. ثم Generate وانسخ المفتاح.
4. في المحرر اضغط **نشر**، الصق المفتاح، واختر «تذكّر الرمز على هذا الجهاز» إن كان جهازك الشخصي.
5. بعد النشر يتحدّث الموقع خلال دقيقة تقريباً. (المسودات تبقى حتى تحذفها من «تم نشرها ← حذف».)

> لا تشارك المفتاح مع أحد؛ كل من يملكه يستطيع تعديل المستودع. يمكنك إلغاؤه من نفس صفحة GitHub.

**ب) تصدير ZIP** — اضغط **تصدير كملف ZIP**، فك الضغط داخل مجلد المشروع (يدمج مجلد `content`)، ثم ارفع التغييرات إلى GitHub بالطريقة المعتادة.

## 5) ملف واحد يعمل بدون إنترنت

```bash
python3 tools/bundle.py     # ينتج dist/quiz-offline.html
```
أرسل الملف عبر واتساب/تيليجرام أو افتحه من الجوال. فيه كل المواد والصور. (الموقع نفسه أيضاً يعمل بدون إنترنت بعد أول زيارة، ويمكن تثبيته على الشاشة الرئيسية.)

## 6) التقدّم والنسخ الاحتياطي

التقدّم (الصح والخطأ) محفوظ في متصفح كل طالب. من **الإعدادات** يمكنه **تصدير تقدّمه** ونقله لجهاز آخر بـ**استيراد**.
للمراجعة: **مراجعة الأخطاء** تجمع كل ما أخطأ فيه الطالب (الأكثر تكراراً أولاً).

## 7) فحص المحتوى

`python3 tools/validate.py` يفحص كل الأسئلة ويخبرك بالخطأ ومكانه. ويعمل تلقائياً على GitHub عند كل رفع (تبويب **Actions**؛ علامة ✗ حمراء تعني وجود خطأ).

## أسئلة شائعة

**عدّلت ولا أرى التغيير في هاتف آخر؟** لم تنشر بعد، أو لم تمر دقيقة على النشر. حدّث الصفحة (في الاستخدام دون اتصال قد تحتاج زيارتين).
**فقدت المسودات؟** المسودات في متصفحك. لا تمسح بيانات الموقع قبل النشر/التصدير.
**كيف أحذف مادة؟** أزلها من الفصل في المحرر (زر ✕)، ثم احذف مجلدها `content/subjects/<مادة>` من المستودع.
**أريد نوع سؤال جديد؟** انظر `docs/DEVELOPER.md` (ملف واحد).
