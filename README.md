# منصة الأسئلة الدراسية · Study Quiz Platform

منصة تدريب على أسئلة المواد الدراسية: **السنة ← الفصل ← المادة ← الدرس**، بدون خادم ولا قاعدة بيانات.
كل المحتوى ملفات JSON بسيطة، وفيها **محرر داخل الموقع** لإضافة الأسئلة وتعديلها ورفع الصور.

An open-source, serverless quiz site: **year → semester → subject → lesson**. All content is plain JSON files, and a built-in editor lets you add/edit questions and images from the browser (phone friendly).

## ماذا فيها؟

- سنوات وفصول ومواد، ولكل مادة **أكثر من مصدر** (مثلاً كتاب + محاضرات).
- 6 أنواع أسئلة: اختيار من متعدد، صح/خطأ، مجموعة صح/خطأ، توصيل، إجابة قصيرة، مقارنة. **إضافة نوع جديد = ملف واحد.**
- محرر داخل الموقع: إضافة/تعديل/حذف/ترتيب الأسئلة، صور بالصق أو الكاميرا (تُصغَّر تلقائياً)، استيراد أسئلة JSON (مثلاً من الذكاء الاصطناعي)، ونشر مباشر إلى GitHub.
- عربي وإنجليزي (RTL/LTR)، وضع ليلي، يعمل على الجوال، ويعمل بدون إنترنت (PWA) أو كملف واحد.
- مراجعة الأخطاء، مؤقت، نجوم، استكمال الاختبار، وتصدير/استيراد التقدّم.
- بدون حسابات حالياً (التقدّم محفوظ في متصفح الطالب).

## تشغيلها

الموقع ملفات ثابتة. للتجربة على جهازك:

```bash
python3 -m http.server 8000      # ثم افتح http://localhost:8000
```

للنشر المجاني: GitHub → **Settings → Pages → Branch: main / root**.

## الملفات

```
index.html            صفحة الموقع
css/app.css           التصميم (الألوان في أعلى الملف)
js/                   الكود   (types/ = أنواع الأسئلة، editor/ = المحرر)
content/              ← كل المحتوى هنا
  catalog.json          السنوات والفصول وقائمة المواد
  subjects/<مادة>/
    subject.json        بيانات المادة والمصادر والدروس
    lesson-1.json …     أسئلة كل درس
    images/             الصور
tools/validate.py     فحص المحتوى
tools/bundle.py       بناء ملف واحد يعمل بدون إنترنت
docs/                 الأدلة
legacy/               النسخة القديمة (ملف HTML واحد) للرجوع إليها
```

## الأدلة

- **[docs/GUIDE.md](docs/GUIDE.md)** — دليل الاستخدام (بالعربية): إضافة مادة وأسئلة وصور، النشر، الملف الواحد.
- **[docs/DEVELOPER.md](docs/DEVELOPER.md)** — للتطوير (English): البنية، إضافة نوع سؤال، تعديل التصميم.

## الأدوات

```bash
python3 tools/validate.py      # يفحص كل الأسئلة (يعمل تلقائياً على GitHub عند كل رفع)
python3 tools/bundle.py        # ينتج dist/quiz-offline.html (ملف واحد للمشاركة)
```
